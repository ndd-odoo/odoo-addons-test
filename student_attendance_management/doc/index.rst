=====================================
User Guide: BIDV Automatic QR Payment
=====================================

This guide explains how to configure and use the **BIDV Automatic QR Payment** module for seamless QR code-based transactions.

.. note::
   This guide assumes that you have already contacted BIDV, completed the necessary agreements, and obtained the required configuration details for integration.

Installation
============

#. Navigate to **Apps**.
#. Search with the keyword *payment_bidv_viin*.
#. Press **Install**.

.. image:: doc_install_payment_bidv_viin.png
   :alt: Install BIDV Automatic QR Payment

How to Use BIDV Automatic QR Payment
====================================

Set up Merchant ID
------------------

1. Go to **Settings**.
2. Under the **BIDV Settings** section, fill in the following fields:

   - **Merchant ID:** Provided by BIDV.
   - **Service ID:** Issued by BIDV for the paygate service.
   - **Secret Code:** Self-generated by your company and shared with BIDV for secure transactions.

.. image:: doc_merchant_setting.png
   :alt: Set up Merchant ID and Secret Code

Enable QR Payment
-----------------

1. Go to **Settings** > **Companies**.
2. In the search bar, type **QR** to quickly find the option.
3. Enable the **Enable QR Payment** checkbox.

.. image:: doc_qr_enable.png
   :alt: Enable QR Payment in Settings

Configure Bank Account
----------------------

1. Go to **Contacts** > **Configuration** > **Bank Accounts**.
2. Create or edit a bank account with the following details:

   - **Bank:** Select **BIDV** (remember to fill the correct bin code for BIDV bank which is 970418).
   - **Account Number:** Enter your BIDV bank account number.
   - **Account Holder:** Select the current company.

.. image:: doc_bank_config.png
   :alt: Configure BIDV Bank Account

3. In the **EMV Configuration** section:

   - **Proxy Type:** Select **Bank Account**.
   - **Proxy Value:** Enter the bank account number (same as above).

.. image:: doc_emv_config.png
   :alt: EMV Proxy Configuration

4. Under the **Bank Connector** field:

   - Select **BIDV**.
   - The system will automatically generate the required parameters.
   - Pay attention to the **Symmetric Key**, which must be shared with BIDV and will be used for data decryption.

.. image:: doc_bank_connector_config.png
   :alt: Symmetric Key

Activate Payment Provider
--------------------------

1. Go to **Invoicing** > **Configuration**  **Payment Providers**.
2. Find **BIDV** and activate it.
3. Ensure the status is set to **Enabled** and **Published**.

.. image:: doc_enable_bidv.png
   :alt: Activate BIDV QR Payment Provider

Done! Your BIDV Automatic QR Payment is now ready for use.

.. image:: payment_bidv_overview.jpg
   :alt: Successful BIDV QR Payment
