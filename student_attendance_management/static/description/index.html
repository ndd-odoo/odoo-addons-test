Zalo Integration

Integrate Zalo Official Account (OA) with Odoo to enable automated message sending through pre-configured templates. Supporting various template types including invoice notifications, order confirmations, payment reminders, and event notifications.

Key Features

Automated message sending via Zalo OA based on configured templates

Multiple template types: transaction, promotion, consultation

Pre-integrated with Sale, Account, Event, and Payment modules

Interactive buttons for enhanced customer engagement

Benefits

Save time with automated template-based messaging
Increase customer engagement through interactive buttons
Multi-language support (English and Vietnamese)
Easy template customization to meet specific needs
Real-time message status tracking and monitoring

Pre-configured Templates

Transaction Templates

  • Invoice notifications
  • Order confirmations
  • Payment reminders
  • Event registrations

Promotional Templates

  • Early payment discounts
  • Special offers
  • Event promotions
  • Payment method promotions

Technical Requirements

Odoo Community/Enterprise 16.0
Verified Zalo Official Account
Python 3.7 or higher
Internet connection for API communication
